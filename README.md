# IRCC PR-by-Country Dashboard

Interactive dashboard of Canadian permanent resident (PR) admissions by
country of citizenship, built from IRCC's open data and embedded on
hogavisa.com.

## Status

This repo is being brought up from a manual, ad-hoc pipeline to an
automated one. See `HANDOFF.md` for the full background and decisions
made so far.

## Data source

IRCC's **"Permanent Residents – Monthly IRCC Updates"** open dataset,
specifically the *Canada – Permanent Residents by Country of Citizenship*
resource:

- Dataset page: https://open.canada.ca/data/en/dataset/f7e5498e-0ad8-4417-85c9-9b8aff9b9eda
- Direct file: https://www.ircc.canada.ca/opendata-donneesouvertes/data/EN_ODP-PR-Citz.xlsx

The filename (`PR-Citz`) matches this repo's existing clean CSVs
(`pr_citz_long_clean.csv`, `pr_citz_wide_clean.csv`), which is a strong
signal this is the same source the original manual pipeline used —
still worth a one-time visual confirmation against a previous manual
export before fully trusting it.

Values between 0 and 5 are suppressed in the source (shown as `--`) and
all other values are rounded to the nearest multiple of 5 — the clean/
transform script needs to handle that.

## Planned layout

```
data/
  raw/      raw IRCC downloads (gitignored, regenerated by fetch step)
  clean/    cleaned long-format CSV, source of truth for the build step
scripts/    fetch / clean / build scripts
output/     generated dashboard HTML (gitignored, deployed separately)
.github/workflows/   scheduled fetch -> clean -> build -> deploy pipeline
```

## Design decisions (confirmed with Nicholas)

- **Plotly CDN**: kept as-is (`cdn.plot.ly`), not vendored or rebuilt.
  Acceptable since the dashboard is iframe-embedded and isolated from
  the rest of the page.
- **Styling**: kept as its current light theme, not restyled to match
  the dark navy/amber blog widget system.
- **Hosting**: GitHub Pages, embedded on hogavisa.com via Wix iframe.
- **Data**: baked in at build time (no live client-side API calls),
  consistent with the no-live-calls convention for his widgets.
